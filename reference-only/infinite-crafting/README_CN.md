# OpenCraft - English Version

OpenCraft is an open-source element synthesis game inspired by InfiniteCraft. Use AI to create infinite possibilities of new elements by dragging and combining different elements!

## 🎮 Game Features

### Chinese Five Elements
- ⚙️ **Metal**
- 🌲 **Wood**
- 💧 **Water**
- 🔥 **Fire**
- 🌍 **Earth**

### Core Features
- ✅ **User System**: Register and login; each player has an independent token.
- ✅ **First Discovery Records**: The first player to synthesize a new element will be permanently recorded.
- ✅ **Chinese AI Synthesis**: Uses local LLM models and supports Chinese prompts.
- ✅ **Bilingual Elements**: Each element includes a Chinese name and an English translation.
- ✅ **Intelligent Caching**: Synthesis results are automatically cached to avoid repeated calculations.
- ✅ **Persistent Storage**: Game progress is automatically saved.

## 🚀 Quick Start

### Option 1: Docker Deployment (Recommended)

**The easiest way to deploy, no Node.js required!**

1. Get SiliconFlow API Key
   - Visit: https://cloud.siliconflow.cn/
   - Register for free and get your API Key.

2. Configure Environment Variables
   ```bash
   cp env.example .env
   # Edit .env file and fill in your SILICONFLOW_API_KEY
   ```

3. Start Service
   ```bash
   docker-compose up -d
   ```

4. Access Application
   - Frontend: http://localhost:5173
   - Backend: http://localhost:3000

📖 Detailed Docker Deployment Guide: [DOCKER_DEPLOY.md](DOCKER_DEPLOY.md)

### Option 2: Local Development Deployment

#### Requirements
- Node.js 18+
- npm or yarn
- SiliconFlow API Key

#### Backend Setup

1. Configure Environment Variables:
   ```bash
   cd server
   cp env.example .env
   # Edit .env file and fill in your SILICONFLOW_API_KEY
   ```

2. Install dependencies and start:
   ```bash
   npm install
   npm start
   ```
   The backend will run at `http://localhost:3000`.

#### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
The frontend will run at `http://localhost:5173`.

## 📖 Instructions

### 1. Register/Login
- Select "Register" for first-time use and enter a username.
- The system will automatically generate a token. **Please save it safely!**
- You can use the token to log in later.

### 2. Start Game
- Drag elements from the list on the right to the workspace.
- Drag two elements together to synthesize them.
- AI will generate a new element related to both elements.

### 3. Discover New Elements
- After synthesizing a new element, it will be automatically added to your element list.
- If you are the first player to discover this element, your name will be permanently recorded.
- Discoverer information will be displayed on the element card.

### 4. Search Function
- Search for Chinese or English names in the element list.
- Quickly find the elements you want.

## 🗄️ Database Structure

### User Table (users)
```sql
- id: User ID
- username: Username
- token: Authentication token
- created_at: Creation time
```

### Element Table (elements)
```sql
- id: Unique element ID
- word_cn: Chinese name
- word_en: English name
- emoji: Emoji symbol
- discoverer_id: Discoverer ID
- discoverer_name: Discoverer name
- discovered_at: Discovery time
```

### Synthesis Cache Table (craft_cache)
```sql
- id: Record ID
- first_element_id: First element ID
- second_element_id: Second element ID
- result_element_id: Result element ID
- created_at: Creation time
```

## 🔧 API Interface

### User Authentication
- `POST /register` - Register new user
- `POST /login` - Login with token

### Element Management
- `GET /elements/base` - Get basic element list
- `GET /elements/discovered` - Get all elements discovered by user (authentication required)

### Game Features
- `POST /craft` - Synthesize new elements (authentication required)
  ```json
  {
    "firstElementId": "base_metal",
    "secondElementId": "base_fire"
  }
  ```

## 🌟 Game Mechanism Details

### Element Uniqueness
- Elements are judged unique based on **Chinese Name + English Name**.
- The same Chinese name but different English name is considered a different element.
- Each element has a unique ID.

### Synthesis Rules
- Any two elements can be synthesized.
- Synthesis results are generated by AI, ensuring relevance to both elements.
- Result cannot contain the names of the original elements.
- Automatically generates corresponding emojis.

### Discoverer System
- Each new element records only the first discoverer.
- Subsequent players synthesizing the same element will not change the discoverer.
- Discoverer information is displayed on the element card.

### Caching Mechanism
- Synthesis results are permanently cached.
- A+B and B+A are considered the same synthesis.
- Avoids repeated AI calculations and improves response speed.

## 📝 Development Instructions

### Adding New Basic Elements
Edit the `baseElements` array in `server/index.js`:
```javascript
const baseElements = [
    { id: 'base_xxx', word_cn: 'ElementName', word_en: 'Element', emoji: '🌟' }
]
```

### Modifying AI Prompts
Find the `generateElement` function in `server/index.js` and modify the `systemPrompt` variable.

### Customizing Frontend Styles
The frontend uses TailwindCSS; styles can be modified directly in each component.
