# OpenCraft English Version - Quick Start Guide

## 🚀 3-Minute Quick Start

### Option 1: Docker Deployment (Recommended) ⭐

**Easiest! No Node.js required, no need to download large models!**

#### Step 1: Get API Key

1. Visit: https://cloud.siliconflow.cn/
2. Register an account (completely free).
3. Get your API Key (format: sk-xxxxxxxxxx).

#### Step 2: Configure Environment

```bash
# Copy environment variable template
cp env.example .env

# Edit .env file
# Required: Replace your_api_key_here with your real API Key
# Optional: Modify AI model, temperature, and other parameters
```

**Minimum Configuration** (only this one is required):
```bash
SILICONFLOW_API_KEY=sk-your-real-api-key-here
```

#### Step 3: Start Service

```bash
# One-click start!
docker-compose up -d

# View startup logs
docker-compose logs -f
```

✅ Seeing "✅ Server started successfully" means success.

#### Step 4: Start Playing

1. Open your browser and visit: http://localhost:5173
2. Click "Register" and enter your username.
3. **Important: Save the token generated by the system!**
4. Start the game and synthesize new elements!

---

### Option 2: Local Development Deployment

**Suitable for developers, requires Node.js environment**

#### Step 1: Get API Key

Same as above, visit https://cloud.siliconflow.cn/ to get it.

#### Step 2: Configure Backend

```bash
cd server
cp env.example .env
# Edit .env and fill in the API Key
```

#### Step 3: Start Backend

```bash
npm install
npm start
```

✅ Seeing "✅ Server started successfully" means success.

#### Step 4: Start Frontend

**Open a new terminal window**

```bash
cd frontend
npm install
npm run dev
```

✅ Seeing "Local: http://localhost:5173" means success.

#### Step 5: Start Playing

1. Open your browser and visit: http://localhost:5173
2. Click "Register" and enter your username.
3. **Important: Save the token generated by the system!**
4. Start the game and synthesize new elements!

## 🔧 Frequently Asked Questions

### Q1: Docker start failed?
**A:** Check the following:
1. Is Docker running?
2. Is SILICONFLOW_API_KEY set?
3. Are ports 3000/5173 already in use?

```bash
# View detailed errors
docker-compose logs backend

# Check environment variables
docker-compose config
```

### Q2: API Key invalid?
**A:** Ensure:
1. API Key format is correct (starts with sk-).
2. No extra spaces or newlines.
3. Confirm the Key is valid in the SiliconFlow console.

### Q3: Frontend cannot connect to backend?
**A:** Check if the backend is running on port 3000.
```bash
# Docker method
docker-compose ps

# Local method
netstat -ano | findstr :3000  # Windows
lsof -i :3000                 # Mac/Linux
```

### Q4: How is the synthesis speed?
**A:** Using the DeepSeek-V3 API, synthesis usually completes within 1-3 seconds. The first synthesis might be slightly slower, but cached combinations will return immediately.

### Q4: Forgot token?
**A:** Token is stored in browser's LocalStorage:
- Press F12 to open developer tools.
- Go to Application/Storage → Local Storage.
- View the `opencraft/user` field.

### Q5: Want to reset data?
```bash
# Delete database file
rm server/cache.db

# Restart backend
cd server
npm start
```
